# FlorishMed China Official Website

Static Astro website for FlorishMed China, an independent non-clinical China hospital navigation and healthcare access guidance service for international visitors, expats, and global patients.

## Commands

- `npm run dev`
- `npm run build`
- `npm run preview`

## Deployment

- Build command: `npm run build`
- Output directory: `dist`

## Positioning

FlorishMed China is not a hospital, clinic, insurance company, doctor booking platform, or emergency service. The website provides general, non-clinical hospital navigation and healthcare access information only.
